# EWT 作业学习助手

升学E网通（EWT）网页端自动化辅助脚本，基于 [Violentmonkey](https://violentmonkey.github.io/) / [Tampermonkey](https://www.tampermonkey.net/) 运行。

> ⚠️ **仅供学习与技术研究使用。** 请遵守学校与平台的各项规定，自行承担使用后果。请勿用于任何违反校规、考纪或平台服务条款的场景。

> 🆕 **第一次用？请看 [新手指南](./新手指南.md)** —— 从注册智谱账号到开始作答，零基础逐步教程。

---

## 功能

### 答题页

| 功能       | 说明                                                         |
| -------- | ---------------------------------------------------------- |
| **自动作答** | 识别题目（选择题 / 填空题 / 语法填空 / 带图题 / 公式题 / 手写上传题），调用 AI 生成答案并自动填入 |
| **自动过检** | 检测到平台「认真度检测」弹窗时立即通过                                        |
| **自动提交** | 全部题目作答完成后才提交（作答过程中不会误触发），并自动确认提交弹窗                         |
| **自批满分** | 进入自批界面后自动批改为满分并提交                                          |

### 视频页

| 功能          | 说明          |
| ----------- | ----------- |
| **2X 倍速**   | 视频自动 2 倍速播放 |
| **自动跳过**    | 自动跳过已看片段    |
| **自动连播**    | 一集结束自动播放下一集 |
| **锁进度条**    | 锁定进度，防止被拖回  |
| **认真度检测秒过** | 弹窗出现即刻点击通过  |

## 安装

需要安装 **两个** 脚本，缺一不可：

### 1. 安装脚本管理器

推荐 [Violentmonkey](https://violentmonkey.github.io/get-it/)（开源）或 [Tampermonkey](https://www.tampermonkey.net/)。

### 2. 安装 bridge 脚本（`ewt-llm-bridge.user.js`）

负责调用智谱 GLM 生成答案。它需要 `GM_xmlhttpRequest` 权限来发起跨域请求，因此必须单独拆成一个脚本。

### 3. 安装主脚本（`增强.js`）

负责页面 DOM 操作、自动点击与 UI 面板。

> **为什么必须拆成两个脚本？**  
> 主脚本需要劫持页面上下文的 `EventTarget.prototype` 来绕过 `isTrusted` 校验，一旦使用 `@grant` 就会被包进沙箱、对页面失效；而跨域请求又必须依赖 `@grant`。两者需求冲突，只能拆开，用 `postMessage` 通信。

### 4. 配置 API Key

进入 EWT 页面后，点击页面右下角的 **📖 悬浮球** 展开面板，再点面板内的 **⚙ API 设置**：

1. 前往 [智谱开放平台](https://open.bigmodel.cn/usercenter/apikeys) 申请 API Key；
2. 把 Key 粘贴到「API Key」输入框（其余字段留空即用默认值）；
3. 点击 **测试连接** 确认可用；
4. 点击 **保存**。

Key 仅保存在你自己的浏览器本地（`GM_setValue`），不会上传到任何服务器，也不会写进脚本源码。

## 配置项说明

| 字段      | 默认值                                    | 说明                                               |
| ------- | -------------------------------------- | ------------------------------------------------ |
| API Key | （空）                                    | 必填。智谱 GLM 的 API Key                              |
| 接口地址    | `https://open.bigmodel.cn/api/paas/v4` | 一般无需修改                                           |
| 带图题模型   | `glm-5.3-flashx`                       | 用于带图题、公式题，速度快且支持图片输入                             |
| 长答案模型   | `glm-5.3-flash`                        | 用于手写上传型主观题，长链条推理更稳                               |
| 超时(ms)  | `180000`                               | 单次请求超时时间                                         |
| 温度      | `0.1`                                  | 取值范围 0~2。越低答案越稳定，答题场景建议保持较低值                     |
| 思考强度    | 默认(max)                                | `low` / `high` / `max`。选 `low` 可**显著提速并省 token** |

> 只有 `glm-5.3-flash` 与 `glm-5.3-flashx` 支持图片输入，其余模型传图片会报错。脚本已按题型自动分档。

**关于「思考强度」**：GLM-5.3 系列**强制开启思维链且无法关闭**（官方限制），  
但可以通过 `reasoning_effort` 调节思考深度。若觉得作答慢、消耗大，把它设为 `low` 即可 ——  
这是官方推荐的正规做法，不影响答案正确性，只是减少中间推理 token。

**关于「温度」**：官方推荐值其实是 `1`，但本项目默认 `0.1`。  
原因是答题场景要求**同一道题每次调用给出相同答案**，高温度会让结果漂移。如需对齐官方可改成 `1`。

## 常见问题

**Q：提示「未检测到 ewt-llm-bridge 脚本」？**  
A：两个脚本都要安装，且都启用。刷新页面后等待 2~3 秒。

**Q：自动作答没有反应？**  
A：先确认 ⚙ API 设置里已填 Key 且测试连接成功。若仍无反应，点「诊断题目」看是否识别到了题目。

**Q：积分/额度消耗很快？**  
A：自动作答每道题都会调用一次模型。带图题耗用更多 token。可在答题前先手动做几道确认效果。

**Q：提示「接口可用，但返回内容为空」？**  
A：这是 GLM-5.3 系列**强制思考**导致的。该系列无法关闭思维链，模型会先输出思考内容（`reasoning_content`）再输出正文；若 token 上限太小，思考链吃掉全部额度，正文就是空串。v3.0.1 已修复：测试请求给足 token 上限，并在正文为空时回退读取思考内容。请更新到 v3.0.1 或更高版本。

**Q：脚本会不会自动提交？**  
A：只有开启「自动提交」开关后才会，且必须**所有题目都作答完成**才会提交。做题过程中不会提交。

## 项目结构

```
增强.js                  # 主脚本：DOM 操作、自动点击、UI 面板
ewt-llm-bridge.user.js   # bridge 脚本：调用 GLM、配置存储
新手指南.md               # 零基础使用教程
```

两者通过 `postMessage` 通信，消息协议定义在各自脚本顶部的常量区。
